# Contributing to Risk2Relief

Thank you for your interest in contributing.

## Getting Started
1. Fork the repository.
2. Create a feature branch:
   ```bash
   git checkout -b feature/your-change
   ```
3. Make focused, minimal changes.
4. Commit with clear messages.
5. Open a pull request with a clear description.

## Contribution Guidelines
- Keep changes scoped and easy to review.
- Update documentation when behavior or usage changes.
- Follow existing project structure and naming conventions.
- Avoid committing generated artifacts, secrets, or local environment files.

## Reporting Issues
When opening an issue, include:
- Problem summary
- Steps to reproduce
- Expected behavior
- Actual behavior
- Supporting logs/screenshots (if available)

## Pull Request Checklist
- [ ] Changes are scoped to one logical improvement
- [ ] README/docs updated if required
- [ ] No sensitive data introduced
- [ ] Local checks/tests (if available) have been run

## Code of Conduct
Be respectful, constructive, and collaborative.
