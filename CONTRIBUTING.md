# Contributing to Risk2Relief

Thank you for your interest in contributing.

## How to Contribute
1. Fork the repository.
2. Create a feature branch:
   ```bash
   git checkout -b feature/your-change
   ```
3. Make focused changes with clear commit messages.
4. Open a pull request describing:
   - What changed
   - Why it changed
   - How it was validated

## Contribution Guidelines
- Keep changes scoped and easy to review.
- Update documentation when behavior or project assets change.
- Do not commit secrets or credentials.
- Ensure filenames and links remain accurate.

## Suggested Pull Request Checklist
- [ ] Documentation updated (if needed)
- [ ] Links and file references verified
- [ ] No sensitive data added
- [ ] Change is focused and minimal

## Reporting Issues
When opening an issue, include:
- Expected behavior
- Actual behavior
- Reproduction steps
- Screenshots or sample files (if relevant)
